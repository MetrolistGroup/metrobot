Note markup reference

Use top-level backtick fences named components-v2, faq, or random. Only one rich block (Components V2 or FAQ) is allowed. Markdown before and after the block is preserved.

Components: text with content; separator; section with content and HTTPS thumbnail; gallery with urls; buttons with label / HTTPS url pairs.

```components-v2
{"components":[
  {"type":"text","content":"# Project links"},
  {"type":"separator"},
  {"type":"buttons","buttons":[
    {"label":"Releases","url":"https://github.com/MetrolistGroup/Metrolist/releases"}
  ]}
]}
```

FAQ fences contain an optional # Title and ## Questions followed by answers. Random fences contain a JSON array of Markdown strings. Save with Ctrl+S (⌘S on macOS). Saves affect only the local working copy.
