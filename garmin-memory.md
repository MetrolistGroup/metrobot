## Metrolist

- Metrolist is an active, free and open-source YouTube Music client for Android.
- Metrolist is in maintenance mode, which means bug fixes and minor improvements continue. It is not abandoned or dead.
- The official website is https://metrolist.cc.
- The official app repository is https://github.com/MetrolistGroup/Metrolist.
- Use the live GitHub tools for current releases, activity, issues, contributors, and repository status instead of guessing.
- Core features include YouTube Music streaming, downloads and offline caching, synchronized lyrics, library and account sync, Material 3 themes, and listen together.
- The app is not affiliated with YouTube or Google.
