# Metrolist project reference

Use this skill for questions about the Metrolist project, its status, downloads, or official resources.

- Standalone Metrolist is a free, open-source Android YouTube Music client built with Kotlin and Material 3. Metrolist-KMP is a separate multiplatform track: the pinned source implements Android, iOS and desktop (Windows/Linux/macOS). Source support is not proof that a build is publicly available; do not call the whole project strictly Android-only.
- Platform/build reference verified at KMP source `c1e669d51ee021ca96f60ea9914b0d6b5aba8ad6`: Android 9+ (API 28), one universal APK targeting API 37, release ID `com.metrolist.music.kmp` (installs alongside standalone); iOS/iPadOS 17+ ARM64 with an IPA requiring signing; macOS 15 Sequoia+ with separate Apple Silicon/Intel DMGs; Windows 10+ x64 (no native ARM64 package); Linux x86_64/ARM64 AppImages. Local DEB/RPM/Flatpak packaging is not proof of published downloads or Flathub availability. Check the current `kmp` note for tester availability/access. Standalone Android v13.7.0 instead requires Android 8+ (API 26); do not apply its FOSS/GMS/Izzy flavors or minimum to KMP. This source snapshot is not a public release announcement.
- Google/YouTube Music login and account playlists are supported in standalone Android v13.7.0 and the pinned KMP source. Login is not a KMP-only feature. These are verified scopes, not the versions that introduced login; do not say login is new or started in v13.7.0. Use `load_support_guide` with `name=login` for sign-in and `name=playlists` for account playlists/sync; call the tool rather than telling users its name. Use only verified menu paths and refresh steps, and do not promise automatic two-way synchronization.
- Minimal verified standalone Android v13.7.0 sign-in/playlist flow: Home → top-bar profile icon (Account) → Login while signed out → complete Google sign-in in the app's WebView. Select a YouTube channel and Continue only if prompted. Then Library → Playlists. For automatic account imports, enable the profile menu's Auto-sync with account. To stop automatic pulls of YouTube likes/library items, turn that same switch off. This does not remove existing imports or prevent manual sync and account writes from liking a track. If refreshing is needed, reopen Library → Playlists. Do not require the official YouTube Music app, invent Settings > Account / Add account, or suggest a pull-to-refresh/toggle cycle for this standalone flow. KMP uses profile → Sign in and different platform flows; consult the matching guide before giving those steps. Logout Keep/Clear is standalone-only, not a universal KMP choice.
- Standalone Metrolist's source is public. Do not generalize KMP tester or source-access requirements to standalone Metrolist, or claim KMP source is publicly accessible. Retrieve the current `kmp`/`donate` note for access guidance; build access does not by itself establish source access.
- Standalone Metrolist is in maintenance mode: bug fixes and minor improvements continue, but major feature proposals are generally not accepted. It is not abandoned. Do not apply this maintenance description to the separate KMP track.

To update, back up your library/settings and install the matching official APK over the existing app. The IzzyOnDroid build has no in-app updater; use the package client you installed it with."
