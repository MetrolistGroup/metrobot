    Formatting help and examples
                
    Use ordinary Markdown. Put custom fences at the top level on separate lines. Names have no special behavior; renaming keeps the authored layout.
    
                
    random: a JSON array of Markdown strings. Whole entries are shuffled and joined by newline on each delivery. Text outside the block stays fixed.
    
                
    faq: Markdown with an optional # title and ## question headings followed by answers. Discord presents paginated answers.
    
                
    components-v2: JSON with a components array. Types: text (content), separator, section (content, HTTPS thumbnail), gallery (HTTPS urls), buttons (label and HTTPS url per button).
    
                
    Use at most one FAQ or components-v2 block per note. Random blocks may coexist outside it. All media and button URLs must use HTTPS.
    
                
    
                
    Examples insert at the cursor without replacing selected or existing text.
